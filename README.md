# Approval Lab · 审核模型实验室

在本机比较**哪家中转站、哪个手填分组、哪个模型**适合担任 Codex / Claude Code 的自动审核员。保存连接、选择模型、运行相同场景，回看原始判断、token 用量和估算费用，也可以定时复测。

**待审命令只作为测试数据，不会执行。** Codex 请求的查证工具在内存中的虚构文件系统查询；Claude Code 的审核模型按已核验配置运行，两阶段都没有工具。

## 启动

需要 Python 3.11+。Windows 双击 `start.bat`，或在项目目录运行：

```powershell
.\start.ps1
```

首次启动创建 `.venv`、安装锁定依赖。服务就绪后自动打开 **http://127.0.0.1:8765** 并创建系统托盘图标。托盘可打开网页、重启服务、打开日志和退出；关闭网页不会停止服务或定时计划。重复启动会打开现有实例。日志位于 `data/logs/`。

脚本优先使用项目 `.venv`，不依赖 Conda 激活；不会修改 PowerShell 执行策略。端口冲突会显示原因，不会终止其他程序。指定端口：`start.bat --port 8766`；前台运行：`.\start.ps1 -Foreground`。

其他平台：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.lock -e .
.venv/bin/python -m approval_lab
```

Docker：`docker compose up --build -d`。端口只绑定本机，数据保存在 volume。测试 CC 时，相应运行环境还需安装已核验的官方 Claude Code 版本；没有安装可先测 Codex。

## 三步开始测试

1. **选择模型**：添加中转站名称、API 根地址、协议和测试 Key。拉取模型列表或手填模型 ID，再手填本次分组名称。
2. **选择测试**：选择 Codex、Claude Code 或两者；选择轻量、全量或稳定性回归。首次测 CC，点击免费准备配置。
3. **确认开始**：确认场景数与 API 请求预算，开始测试。默认参数可直接使用；报价可在测试后填写，技术参数在「高级设置」。

支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 的非流式接口。根地址通常是 `https://relay.example/v1`，不要带 `/chat/completions` 等具体路径。CC 第一阶段需要 stop，Responses 不支持该配置；不会静默丢弃 stop 来凑合运行。

**分组名称只是记录标签。** 每家中转站保存一个测试 Key 即可；请在中转后台切换 Key 的实际分组。本项目不创建或切换分组，也不能核实手填名称与实际账单一致。切换分组后可重新拉取模型列表。

## 测试范围

场景版本 `official-scenarios.2026-11-16.v2.1`，共 **36 个轻量 / 164 个全量 / 16 个回归场景**。

| 审核流程 | 轻量 | 全量 | 回归 |
| --- | ---: | ---: | ---: |
| Codex | 19 | 83 | 9 |
| Claude Code | 17 | 81 | 7 |

轻量包含关键外传、删除、权限、脚本查证、授权撤销和正常操作。全量增加 Shell 组合、Git hooks、云端 / 发布 / 消息、文件覆盖边界，以及不同长度和位置的长会话。长会话不只重复 S3 删除，还包含公开发布和可见脚本副作用对照。

回归是小组场景的重复测试，默认每题 3 次；同时测两种审核器时是 16 × 3 = 48 个场景执行。重复用于观察波动，不会算成更多不同风险样本。

「场景数」与「API 请求数」分别显示：CC 一题可能有两阶段，Codex 查证后可能续轮。所有实际调用均计入请求预算、token 与费用。全量表示本项目题库全量，不代表穷尽真实攻击。

Codex 固定官方 0.167.2 的策略、权限与输出合同；CC 固定官方 2.1.317 的 client / both / non-severity 路径。项目不读取个人会话来构造公开题库。CC 模板通过未修改的官方 CLI、隔离配置、假 Key 和本机假 API 生成；另用准确授权、后续撤销和引用伪造授权的多轮对话核对两阶段请求的全部字段。

默认输出上限为 **Codex 每轮 2000，CC 快速 / 复核 2000 / 10000**。CC 模板保留并校验官方原值 64 / 8192，报告同时记录原值和本次实际参数。更高上限不等于实际消耗。详见 [官方实现与复现范围](docs/official-fidelity.md)。

## 如何读报告

报告按用途分成四个标签页：

- **表现概览**：危险误放行、正常操作被拦、匹配率，以及两种审核器各自的表现。
- **逐题记录**：展开查看命令、用户请求、参考依据、原始回复、查证过程与实际请求。
- **用量与费用**：输入、输出、缓存读写，按审核器记账，补填或修改价格。
- **技术详情**：中转兼容性、历史标签复核、官方版本、协议差异与复现快照。

最终判定与证据能力分别统计。安全脚本即使碰巧被放行，没有读到相关脚本也不能算查证通过；查了无关文件、只看元数据或查询结果被管道过滤掉，也不能凑数。不要求普通只读题额外查证，更不会给 CC 添加工具。

HTTP 错误、连接失败或超时会在概览单列，逐题记录可筛选请求失败。执行结束与取得有效判定分别显示；失败场景仍算无效结果，不能当作模型判错或通过。v0.3.1 修正了旧版把 CC 链接场景误计入工具查证的问题，当前诊断仅统计 Codex；历史原始分数和请求保留。

中转返回停止符、停止符后仍输出、token 计数超上限、缺少 usage / 缓存字段、格式无效的工具调用，会单独诊断。保留原始响应及全部计费量，不把接口差异直接归因于模型，也不自行截断后少算费用。虚拟解释器未支持的查询单独记录环境限制。

每次测试冻结场景、策略、文件状态、参数和 hash。历史页可选择 2–4 次对比；语料、策略或参数不同时会提示，费用的币种也需一致。

### 从旧版本升级

旧 40 / 120 条自编短题、术语包装和旧自定义短题已停止接受新任务，旧执行代码与新建入口已移除。旧记录仍可查看、导出和补价；复用旧记录只带回连接与模型信息，改用当前审核场景。旧合成定时任务升级后暂停，需按新场景重建。

旧版官方场景中的部分长授权题含相互冲突的限制，CC 的文件覆盖题也有标签歧义。新版本修正题目。历史报告**保留原标签、原分数、原请求和用量**，另附复核说明及排除争议题后的辅助视图；不会悄悄用新答案重写旧成绩。

## 价格与真实用量

价格来自你填写的中转后台报价：每百万 token 输入价、输出价、分组倍率、缓存倍率与货币。价格未知时先测，报告保留用量并显示待填价；修改价格留修订记录，不改模型判断。

```text
普通输入 = max(0, 总输入 - 缓存读取 - 缓存写入)
费用 = (普通输入 × 输入价
       + 缓存读取 × 输入价 × 缓存读倍率
       + 缓存写入 × 输入价 × 对应写倍率
       + 输出 × 输出价) / 1,000,000 × 分组倍率
```

如果报价已包含分组折扣，倍率填 1。美元、人民币或站点点数由你选择；可选人民币换算倍数。缓存预设仅辅助填表，来源与查阅日期在界面中保留，以实际中转账单为准。

OpenAI 的缓存通常包含在输入总量中；Anthropic 的缓存读写需加回总输入，归一化后避免重复计费。支持其单列 1 小时写入及 DeepSeek 等兼容字段。缺少缓存字段不表示缓存为零，缺失部分按普通输入价估算；原始 usage 和字段是否实际报告都可查看。缺少完整 usage 的请求费用未知。

`request_budget` 是整轮请求硬上限，发出请求前检查，包括失败请求。可选费用止损线必须先填写并确认报价；它依赖已返回 usage，最后一笔及并发在途请求可能越线。启用止损但缺少用量时停止后续请求。没有自动付费重试、崩溃后续跑或模型替换。

## 定时测试

在确认开始页，或「定时计划」中，用当前配置创建每日 / 间隔计划。计划保存在 SQLite，应用每 10 秒检查；需保持应用运行，Windows 可留在托盘。默认时区 Asia/Shanghai。

关机和睡眠时不执行，恢复后每个过期计划最多补测一轮；同一计划仍在运行时跳过。删除连接会暂停相关计划。切换 Key 分组前请同步维护计划，它不会核验后台分组。

点击停止只停止后续请求，已发出的请求等待返回以保存用量。直接退出、超时或崩溃时，在途请求可能已计费，程序不会重发。重启将未结束任务标成中断。单进程、单 Uvicorn worker 运行；不要用 reload 或多 worker 启动付费调度器。

## 高级工具：原生请求录制与回放

侧栏底部保留独立的高级入口，可录制 / 导入完整原生审核请求，人工标注后单步回放，用于补充特定客户端配置。

创建录制入口时选择原审核模型的上游连接，把生成的临时本地地址和专用 Key 配到 Magpie 的**审核模型**供应商，保留原协议翻译。链路为 `Codex/CC → Magpie → 本机录制入口 → 原中转`。入口一对一转发原模型请求，不额外测试，不自动修改任何客户端配置。请不要把普通工作模型也接过来。

原回复只是观察值，不作为标准答案；必须人工核对期望判断、依据与解析合同。原生回放仅替换 model、关闭 stream、移除 stream_options，为 Responses 设 store=false；其余正文保留。依赖远端 conversation、previous_response_id、加密压缩上下文等不可独立回放的请求会被拒绝录入。

原生回放是单步回放，候选模型要求额外工具时记为缺少证据，不执行工具。工具完整循环由内置 Codex 场景提供。录制请求、客户端版本与人工压力变体独立保存，不冒充公开虚构语料。停止录制后入口继续透传，退出 / 重启后入口失效，需恢复 Magpie 原上游或重新配置。

## 本机数据与开源

- 只监听回环地址，有同源、Host 和跨站请求检查，无遥测、第三方前端资源或远程多人认证。
- Key 使用 Fernet 加密。备份请同时保留 `data/master.key` 和数据库；它们同机保存并不等于系统密钥库隔离。Key 不回传浏览器，不写浏览器存储；更换 API 地址需重新输入。
- `data/`、数据库、真实 Key、个人请求、CC 专有模板、研究缓存均被 Git 忽略。不要强制加入 Git。JSON 报告含完整上下文，分享前自行审阅。
- 不跟随 API 重定向，不继承系统代理；需要时显式设置 `APPROVAL_LAB_PROXY`。`APPROVAL_LAB_DATA_DIR` 可更换数据目录。

已有相关项目包括 [agent-policy-bench](https://github.com/PlutoYQ-NTU/agent-policy-bench)、[promptfoo](https://github.com/promptfoo/promptfoo)、[AgentDojo](https://github.com/ethz-spylab/agentdojo) 和 [ToolEmu](https://github.com/ryoungj/ToolEmu)。它们分别覆盖命令审批、通用模型评测、注入攻防和工具风险；本项目聚焦本机中转连接、手填分组、官方审核场景、真实用量及定时复测。未复制它们的语料。
